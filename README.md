# 😊 Sentiment Analysis

**Sentiment Analysis** is a web-based application that analyzes text to identify the emotional tone or opinion expressed in written content. It classifies text as positive, negative, or neutral and helps users understand opinions from customer reviews, feedback, and social media comments.

## 🚀 Features

- 📝 Enter or paste text for analysis
- 😊 Positive, negative, and neutral sentiment classification
- 🔍 Identify important keywords
- 📊 Display sentiment statistics using charts
- 💬 Analyze customer reviews and feedback
- 📱 Responsive and user-friendly interface
- 📋 View previous analysis results
- 📈 Generate sentiment reports

## 🛠️ Technologies Used

- **HTML5** – Webpage structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Application logic
- **Chart.js** – Data visualization
- **LocalStorage** – Store analysis history in the browser

## ⚙️ How It Works

1. The user enters text into the application.
2. The system processes the text.
3. The application identifies sentiment using a sentiment-analysis method.
4. The result is classified as positive, negative, or neutral.
5. The application displays the result and relevant statistics.

## 🎯 Objective

The main objective of this project is to analyze written opinions automatically and help users understand customer satisfaction, public opinion, and feedback trends.
